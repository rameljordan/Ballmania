 Ballmania

A simple game made in Scratch 

How to Play???
- you can control the soccer ball using the four arrow keys, mainly(up, down, left, and right keys)
- the goal of the game is to return the soccer ball "sprite 3" to the house. Each time the ball makes contact with any other sprite, the ball comes back to its starting point, in front of "Mr.Whiskas"
